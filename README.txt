Edit the COMPANY object at the top of script.js to change company details throughout the website. Phone links use the phone setting automatically. Email links, footer details, page title and description all update from the same settings.
Upload ALL files in this package together: index.html, script.js, style.css and assets/. The updated index.html is required for the shared settings to work.
The logo is an image: changing the company name in JavaScript cannot change lettering inside the logo image.
